# ScrollSaw Studio APK
1. Create a new empty GitHub repository and upload everything in this folder (keep the .github folder).
2. Open the Actions tab, run "Build APK", wait about 5 minutes.
3. Download "scrollsaw-debug-apk" from the run, unzip, copy app-debug.apk to your phone and install it (allow unknown apps).
Known limits: file downloads (SVG/PDF/PNG) and the Print button need native plugins in the Android WebView and are not wired yet.
